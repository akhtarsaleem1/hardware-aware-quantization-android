# Journal target verification record

Checked: 2026-08-22 (Asia/Karachi)

## Scope and publisher facts verified

The official Elsevier page identifies *Journal of Systems Architecture* (JSA)
as an embedded-software and systems-architecture journal whose scope includes
mobile systems, application-specific architecture, design methodologies, and
software-oriented hardware/software co-design. It explicitly warns that a case
study must contribute more than a design for one software application. This
supports JSA as the best thematic target only if the paper emphasizes the
reusable benchmark protocol, raw evidence, statistical rank stability, and
failure-aware configuration selection.

Official journal identifiers: print ISSN 1383-7621; online ISSN 1873-6165.
The official page displayed an open-access APC of USD 2,450 excluding taxes and
a subscription route with no publication fee. These values are time-sensitive
and must be rechecked immediately before submission.

Official source:
https://www.sciencedirect.com/journal/journal-of-systems-architecture

## SCIE verification

Clarivate's Master Journal List (MJL) remains the required authority for an
SCIE statement. Direct browser access to the live MJL profile failed before the
page opened because the local Codex browser sandbox could not initialize. The
public read-only web index also returned no journal-specific result for either
JSA ISSN. Therefore this project does **not** label JSA as SCIE-verified.

Before submission, a human must open the live MJL, search both ISSNs, and save a
dated export or screenshot showing the exact Web of Science Core Collection.
An impact factor, publisher page, Scopus listing, or third-party journal list is
not accepted as a substitute.

## Novelty recheck

A focused 2025-2026 search found adjacent work on quantized mobile NPU
super-resolution and current on-device generative-model quantization, but no
closer classification study than Gherasim and García Sánchez (arXiv:2511.13453),
already recorded as P33. P33 substantially overlaps precision, accelerator,
threading, accuracy-latency, and Pareto comparison. The present paper therefore
must not claim novelty for those topics. Its defensible scope is the narrower
combination of immutable per-inference observations, randomized repeated
blocks, tail latency, uncertainty/effect size, memory and thermal context,
effective-delegate/failure logging, and rank-stability analysis on lightweight
classifiers and a lower-end consumer phone.
